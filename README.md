# HomeRacker for Onshape

`features/homeracker.fs` defines one **Homeracker** custom feature for making
an individual support, connector, or plain panel in an Onshape Part Studio.
Dimensions are in millimetres and use the upstream 15 mm grid, 2 mm walls,
0.2 mm fit allowance, and 4 mm square lock pin geometry.

## Use

The feature is available in the [Homeracker Onshape document](https://cad.onshape.com/documents/98b88f085d92f997adf9129c/w/d000ce49db154cdce9e482df/e/6d2975b4f296af4b2ed01e1f).

Create a Feature Studio, paste the FeatureScript file, add the custom feature
to a Part Studio toolbar, then select **Type**:

| Type | Controls |
| --- | --- |
| Support | Length in 15 mm units, optional X pin holes |
| Connector | 1–3 dimensions, directions, optional X/Y/Z pull through |
| Panel | X/Y grid size, InterFit or full cover, per-edge and corner mounts |

Connectors use the upstream direction priority: +Z, −Z, +X, −X, +Y, −Y.
Invalid direction counts are clamped to the chosen dimension's valid range.
Panels have a minimum 2 × 2 grid.

The file targets FeatureScript standard library `3095.0`. If a Feature Studio
in the destination Onshape account uses a newer header, replace only the first
two lines with the header generated by that Feature Studio before pasting.

## Geometry and current limits

The support's square pin passage has the exact upstream cross sections:
5.6 mm at each entrance, 4 mm at ±6.7 mm, and 4.8 mm at its centre. Its
outer block has 1 mm edge chamfers. Connector arm dimensions and direction
selection, arm hollowing, 0.8 mm lead-ins for square pin holes, printing base
trim, and 5/6-way printing tetrahedron follow the OpenSCAD construction.

The native panel implements the upstream grid footprint, 2 mm surface,
13 × 2 mm L-shaped corner plates, square lock pin passages, optional
intermediate edge mounting strips with bridges and gap fillers, and full cover
plate. The connector's inner cavity chamfer is built on the arm-side plane
and the outer arm chamfer excludes that plane. The OpenSCAD
`optimal_orientation` printing rotation is not a user control in this initial
feature. The feature does not make lock pins or panel cutout variants.

The [comparison workflow](comparisons/README.md) includes a pinned toolchain,
15 upstream SCAD fixtures, an offline batch-feature builder, and STEP/STL
comparison tools. Run `mise run setup`, `mise run reference`, and `mise run test`
to prepare the references locally.

The feature compiles in Onshape and all 15 comparison cases regenerate through
the Onshape MCP server, producing one solid each with no notices. Bounding boxes
match the SCAD references; volume differences are below 0.005%. STEP surface
comparison remains pending. The comparison tools in `scripts/` can
compare exported Onshape bodies with the upstream OpenSCAD reference meshes.
No printer fit claim should be made until the intended Onshape version and
print material are verified.
