# HomeRacker logo

`homeracker-logo.svg` comes from the [HomeRacker assets repository](https://github.com/kellerlabs/assets/blob/0070ea2482ac296e6660234b778959b39484f1c5/homeracker/img/homeracker_logo_single_color.svg).
The [HomeRacker logo guide](https://github.com/kellerlabs/homeracker#-logo) invites compatible models to use the logo.

The file keeps the original vector paths and colors.
We removed a hidden bitmap image and editor metadata to reduce its size.
Onshape displays feature icons in grayscale.
